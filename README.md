# Nothing — Landing Page

A responsive landing page for Nothing, a London-based consumer tech brand. The page presents recommended products, browsing by category, information about the company and a contact form. It is built with semantic HTML and SCSS using the BEM methodology, with no JavaScript required for the interactive parts.

## Technologies Used

- HTML5
- SCSS (BEM methodology, variables, mixins)
- CSS Grid and Flexbox
- Parcel (bundler)
- ESLint, Stylelint, Prettier
- GitHub Pages (deployment)

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/recurse1337/nothing-landing-page.git
cd nothing-landing-page
```

2. Install dependencies:

```bash
npm install
```

3. Run the project locally:

```bash
npm start
```

## Features

- Fully responsive layout for mobile, tablet and desktop, built on a 2 / 6 / 12-column grid
- Burger menu implemented in pure CSS with the `:target` selector
- Smooth scrolling to page sections
- Subtle hover animations with a shared duration and easing
- Contact form with built-in validation
- Optimized images in WebP format with lazy loading
- Sticky footer image revealed on scroll
